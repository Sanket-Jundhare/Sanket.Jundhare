# Portfolio

Welcome to my personal portfolio website built with **React** and **Vite**.

This project showcases my skills, projects, and contact information. It's fast, minimal, and deployed using **GitHub Pages**.

## 🚀 Tech Stack

- React 19
- Vite 7
- JavaScript / TypeScript (optional)
- GitHub Pages for deployment

## 📦 Getting Started

To run locally:
